# Amigo — Rust course platform prototype

Arabic RTL course catalog generated by Rust and integrated with Firebase Authentication and Cloud Firestore for student accounts and profiles. The courses and faculties are illustrative examples. The demo does not imply institutional approval.

## Run and build

Install stable Rust, run `cargo test`, and `cargo run`; or run `cargo run --release -- --export dist` to generate the static preview. Node is only used to check client scripts. The development HTTP server is not hardened for public production deployment.

## Accounts and security

Email and password sign-up, sign-in, password reset, per-user student profile, and course recommendations use the configured Firebase project. The Firebase client configuration is public by design; authorization is enforced by Firebase Security Rules, not by obscuring the configuration. Deploy `firestore.rules` to the intended database before enabling registration; these rules limit a student to their own profile and validate the permitted fields. Never use test-mode open rules. Enforce secure authorization separately for every future feature. No payment, course access, instructor or admin privileges are implemented.

If account creation succeeds but writing a profile fails, the user can sign in and complete their profile later. Email verification, enrollment, subscriptions, lesson player, and revenue reports remain to be implemented. The page is private to the site owner until access is deliberately changed. Legal content, policies and example courses are not final.
